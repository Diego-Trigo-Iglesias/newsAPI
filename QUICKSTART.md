# 🚀 INICIO RÁPIDO - NewsHub

## Configuración CERO requerida

Esta aplicación funciona **inmediatamente** sin necesidad de:
- Claves API
- Registro en servicios
- Configuración de archivos
- Variables de entorno

## Instalar y Ejecutar (30 segundos)

```bash
# 1. Instalar dependencias
npm install

# 2. Ejecutar
npm run dev

# 3. Abrir navegador
# http://localhost:3000
```

## Con Docker

```bash
# ¡Un solo comando!
docker-compose up --build

# Luego abre: http://localhost:3000
```
